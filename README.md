# Transformers Count Cards

Code for *Do Transformers Learn to Count Cards?*

Python 3.11+. Install with `pip install -e .` or use `pip install -e '.[ml]'` for training and analysis.

Full reproduction requires the authors’ archived datasets, checkpoints, and runners. See the [final protocol and results](https://github.com/ethanlou36/transformers-count-cards/blob/c6643b526efecc9a87b582b5cf0682e88210e39b/reports/three-seed-2026-10-14/report.md#deliverables-and-regeneration).
